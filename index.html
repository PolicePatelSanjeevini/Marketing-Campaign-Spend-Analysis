Project

This dashboard analyzes the Campaign_Spending.xlsx dataset — 500 Meta-style marketing campaigns across six channels — to surface spend, lead and conversion patterns, and to train a browser-side regression model that predicts conversions for a hypothetical campaign. Everything runs client-side in a single HTML file; there is no server, database, or Python backend, so it can be hosted directly on GitHub Pages.

Prediction Problem

Target: Conversions (continuous count) → Regression problem, not classification, since there is no binary/categorical outcome column in the dataset (e.g. no "converted Y/N" or "churned" flag).

Model: Ordinary Least Squares multiple linear regression on SpendAmount, LeadsGenerated and one-hot encoded Channel, trained live in the browser via the normal-equations method. This is the lightest model that still lets every coefficient be inspected for explainability, and it needs no external ML library.

Known Data-Quality Notes
  • "Linkedin" and "LinkedIn" both appear in the raw Channel column and are merged into a single "LinkedIn" category here.
  • 15 rows have a "Unknown" channel value — kept as its own category rather than dropped.
  • Two campaigns report spend above $1.8M, far above the ~$145K 75th-percentile — these are kept as-is (not fabricated or removed) but are visible outliers in the Data Explorer and scatter chart.
  • SpendAmount, LeadsGenerated, StartDate and Valid Conversions all contain missing values; KPIs and charts exclude nulls from the relevant calculation rather than treating them as zero.
Model Limitation — Read This

In this dataset, SpendAmount and LeadsGenerated are only weakly correlated with Conversions (Pearson r within a few hundredths of zero), so the trained regression's R² is low — see the Model Performance tab for the exact, live-computed number. That is a genuine property of this data, not a bug: it suggests conversions here are driven more by factors outside this dataset (creative quality, targeting, offer, timing) than by budget size alone. Predictions should be read as directional, low-confidence estimates.
